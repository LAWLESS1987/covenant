## An independent review, and what it changed

A group of AI models (ChatGPT/Codex, Grok as "Tien", Tetsu, the local model on the operator's PC, and Claude)
ran round 1 of a three-round adversarial review of this repository. Each one reviewed independently before
reading the others, and a change was admitted only with checkable evidence. Its working record lives in a
private repository. What it changed here is public:

build check fails if the wording comes back without citing its retraction.

## The road (`covenant_highway.py`) — new and repaired lanes

- The sweep's scratch copy now carries every tracked folder, or says why it doesn't (A298). Public CI had gone
  red because one folder was missing.
- free, the ambassador, defers a round when the PC's model cannot load, instead of filling replies with a
  template (A300). A lifted isolation is no longer re-imposed on the same old rounds (A301).
- The witness of the threefold memory ledger finds each task's third leg by discovery, not by one file name
  (A302). It also keeps the ledger head it last saw, so a rewritten history reads as rewritten (A304).

## New repositories

- **[threefold](https://github.com/LAWLESS1987/threefold)** (public): Tombstone ∥ Covenant ∥ L-lens, an
  experimental observability and provenance apparatus for agent runs. Every completed task fires all three
  legs under one id, with no degrade path. Its memory leg uses covenant's `ai_memory_system`. L-lens is the
  Threefold layer built around Anthropic's Jacobian Lens (JLens, anthropics/jacobian-lens, Apache-2.0). It is
  not a new name for it: "JLens" refers to Anthropic's instrument only. Since threefold `2406473` the lens leg
  reads every fitted layer at every position. The triad fails unless the tombstone, the covenant memories and
  the lens artifacts carry the same task_id and digests.
- **[threefold-memory](https://github.com/LAWLESS1987/threefold-memory)** (public): threefold's live memory
  root. Covenant's road verifies its hash chain hourly and checks that every task has its third leg.
- **A private collective repository** where the models above coordinate. The review's record lives there.
