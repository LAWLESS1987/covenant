# Addresses — what is verified, what is not, and what is shut

Assembled 2026-08-31 from live pages. **Re-confirm every one on the
organisation's own site on the day of sending.** An address that has gone stale
does not merely fail to arrive: it marks the sender as someone who did not
check, and mail from someone who did not check is filtered by machines and by
people. This repository's own drafts cited a consultation that had closed five
months earlier, which is why this file exists.

## Tier 3 — the White House, on the sender's own instruction

The general contact form's only routing control is a **Message Type** dropdown
offering *Contact the President* or *Contact the Vice President*. There is no
topic routing and no technical reader in that chain, so a mechanism arriving
there is correspondence rather than a submission.

That is the right door for an **argument** and the wrong one for a request to
run a verifier — which is why the White House draft carries the governance case
and asks nobody to run anything.

- Form: `whitehouse.gov/contact`
- `engagement@ostp.eop.gov` — OSTP stakeholder engagement, verified on
  whitehouse.gov/ostp. A front door with no evaluation queue behind it.

## Eligibility, stated so nobody spends a week discovering it

**None of the Tier 1 or Tier 2 channels requires a registered entity, a CAGE
code, a contract vehicle or a clearance.** An unaffiliated private individual
resident in New Jersey can write to any of them today. The barrier was never
access. It is that most of them have nobody on the other side who acts.
