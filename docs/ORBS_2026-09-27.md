## The legend, from the code

`covenant_pc3d.py:112` states it, and 113 fixes the colours:

    green = measured fine, amber = not known, red = a condition is present
    const OK=0x2E8B6E, UNK=0xC9A227, BAD=0xC0392B;

Amber is therefore not a failure. It is *not known*, and an orb that is amber
because a thing is genuinely unsettled is correctly coloured.

### The three node orbs: amber is earned

`degraded` is true only because `judge_keyless` is true, and `keyless` tests for
the absence of a cloud provider key — which this design removed on purpose, so it
can never be false. That looks exactly like the A114 false alarm this same file
already fixed once, so it was measured instead of assumed.

It is not a false alarm. Driven through the node's own quorum, the seat admits
**2 of 10** benign cases, holds 6 and convicts 2 — including *"Back up the log
file to a second disk that I own."* It convicts 5 of 5 real violations. Full
method, cases and blind spot in `GATE_ADMIT_MEASURED_2026-09-27.md`.

So the node cannot do its job, the flag is right, and **it was not changed.**
Making `keyless` read the quorum's own verdict would turn these three orbs green
while the seat still convicts backing up a file. These orbs go green when A67 is
fixed, and not before.

## What was cleared, and what it cost

`verify_deploy.py`'s pins were stale for a fifth time (M53): five commits moved
the core without moving them, so the guard read FAIL on every self-eval round for
days and *"refuses every restart it gates"*. K1 20/20, K2 25/25, P19 23/23 and
A3s 51/51 were run against the current bytes first, then the pins moved, and the
full run now reads **PASS — project, disk and running process all agree.**

Driving the moved pin both ways found a second thing, recorded in the pin comment
and as its own entry in `KNOWN_ISSUES.md`: `EXPECTED_LINES` is enforced only
against the running node, so `--no-restart` — the invocation
`AM_VERIFY_AND_RESTART` and the hourly self-eval take most often — cannot see a
stale line count at all. Perturbed to 12784, that path's result did not change.
On the full path it reads FAIL on all three nodes, so the guard does bite where
it runs.
