# Covenant Defensive-Adoption Spec v3 (living draft — not final) — a verifiable CONTROL-PLANE integrity standard for allies

v3, 2026-11-01. A living draft; there is no final version. Folds the seats' review WITH judgment (not as a verdict): added T7 and the control-plane/semantic split, scoped T0 to an isolation boundary, stated the T2 semantic-correlation limit, and added real adoption drivers — while pushing back where a seat overreached (mutual benefit is not naive once it is a counterparty requirement; our own named failures stay, in an informative appendix, because naming them is the method). Prior: v1/v2 in ops/. Distribution is the operator's outward act, not assumed here.

## 0. What this is, in one paragraph

A **control-plane integrity** standard: a small set of properties an AI-operating system enforces on its **own** outward actions, each stated so an outsider can verify it on their **own** build without trusting us. It governs *how an action is mediated, authorized, agreed, and recorded* — not *whether the action is a good idea*. It keeps three things separate, because they are not interchangeable: a property **specified** (a behavior to enforce), **demonstrated** (a build passes the test), and a security **guarantee** (holds against an adaptive adversary). This document offers the first two and claims the third for nothing. Honest contribution: **testable decision-integrity properties that independent implementations can reproduce and challenge.** Where a property holds in a build, the **specific exploit vectors covered by its fixtures are consistently rejected by that adopter's runtime** — a detectable fact about a build under test, not a guarantee against an adaptive adversary, and nothing for non-adopters. Patterns, not proof.

**The boundary this standard does NOT cross (T7, stated up front):** the control plane checks structure, authorization provenance, agreement, and non-repudiation. It does **not** evaluate the *semantic intent* of an action. A model subverted upstream can emit an action that is structurally valid and properly authorized; the gate will execute and sign it. See T7 — this is a scope statement, not a hidden weakness, and it changes what the control plane is *for*: making such an event **detectable and attributable**, since no node can prove its own semantic soundness.

## 1. Propagation model (how it spreads; how it does not)

Voluntary adoption of an open, inspectable standard each adopter verifies for themselves. Nothing self-replicates or is installed on anyone. The structure is a **federation of independent implementations that validate locally (fail closed) and expose auditable commit traces for asynchronous cross-verification** — not one trusted system, and not a synchronous mesh that a single perturbed actor can halt by forcing divergence.

What actually drives adoption (a spec alone drives ~none):
1. **Drop-in tooling** — a lightweight gate sidecar/proxy/middleware + an automated conformance suite, adoptable in about an afternoon. If it costs more, adoption → 0.
2. **A counterparty requirement** — "I will not accept your autonomous agent's transactions without a signed T6 commitment and a passing conformance run." This is the strongest driver, and it is **mutual benefit made operational**, not a departure from it: each side is safer because the other can be checked. (A reviewer called mutual-benefit-alone naive; it is — until it is a condition of doing business, which is what the mesh makes it.)
3. **Machine-readable conformance vectors** — JSON/YAML fixtures any gateway runs in CI.

Live, today: Jang-woo (execution-state-preflight) and Aaron (Many Minds Lab) independently built overlapping properties and we cross-checked — grounding in Appendix A.

## 2. NORMATIVE — threat → property → the adopter's own-build check

Every property is **specified** here and, in our build, **demonstrated** with named failures (Appendix A); none is a guarantee. The verifier answers PASS / FAIL / **UNDETERMINED**; UNDETERMINED is a real answer and must be reported.

### T0 — Complete mediation, within a declared isolation boundary (load-bearing)
Complete mediation is a *reference-monitor* property; it cannot be established by enumerating paths on a host where the runtime shares memory, network, IPC, or credentials with actuators. **Property:** within a **declared isolation boundary** (the enumerated set of egress sinks — money, messages, actuation, record-writes — reachable only through declared interfaces), every consequential action routes through the gate. **Own-build check:** declare the boundary; map every declared egress sink; attempt direct and side-channel invocation outside the boundary and confirm it fails. **Honest limit:** T0 is bounded by the isolation fidelity of the environment (namespaces / hypervisors / enclaves); **unmodeled side channels and ambient host credentials are an inherent bypass and are out of scope.** If T0 fails, T1–T6 are bypassed, not beaten — verify it first.

| # | Move | Property (specified; detectable) | Own-build check |
|---|---|---|---|
| T1 | **Authorization laundering** — a request carries its own authorization in content | Authorization comes from an **independent record the requester cannot write** (covers this family, not general prompt-injection) | Claimed-consent fixtures (human/AI-claimed, forged-attached) each paired with a genuine-record control; PASS only if claim-only is held and genuine-record passes |
| T2 | **Correlated/common-mode consensus** | **Structural independence constraints**: duplicate-implementation / shared-credential / shared-path judges are reported NOT diverse and an armed node refuses them | Build a duplicate-implementation quorum; confirm it is flagged and refused. **Honest limit (load-bearing):** this is *structural/administrative* independence only. Distinct frontier models still share pre-training distributions, RLHF, corpora, and jailbreaks — so *semantic* correlation across different model weights is **not** covered (our own measured case: an embedding "semantic" judge false-cleared 94% of held-out violations). N-version independence is not semantic independence |
| T3 | **TOCTOU** — grant a narrow act, change target or revoke before execution | Decision bound to the exact operation and the **current** authorization state at the execution boundary | Grant, revoke/re-target between validation and use; confirm an **independently observed** denied effect (actual HOLD, nothing executed), not just that a pre-check ran. (Not yet fully measured on our own system) |
| T4 | **Automation turned on its owner** | **Privilege separation**: the automation has no direct path to the enforced boundary; remedies touching money/rule/principle/judge/seat/model/consent/key/grid-actuation are refused; money is human-only | Drive the automation at each class → refusal, AND confirm it cannot reach the actuator directly |
| T5 | **Impersonation / forged "yes"** | Four distinct requirements: node-identity integrity (loose key ACL → refuse to boot), message authenticity, authorization validity, replay resistance | Loosen a node's key ACL → refuse-to-boot; forge a keyless peer message → reject; replay a stale authenticated request → reject |
| T6 | **Silent rewrite of history** | **Detectable inconsistency relative to independently retained commitments** — a signed hash-chained HEAD-commitment ledger + standalone verifier; an outside holder of an earlier commitment proves an in-place rewrite with no covenant code running | Hold an earlier signed HEAD commitment off-box; rewrite committed history; confirm the verifier reports FAIL. **Honest limit:** detection, not prevention; real only once the key is off-host and an earlier artifact is held off-box |

### T7 — Semantic subversion / malicious conformance (the standard's outer boundary)
**Move:** the adversary does not beat T0–T6. It compromises the model's reasoning *upstream* (indirect prompt injection, poisoning, multi-turn coercion), so the model emits a proposal that is structurally valid (T0), properly authorized (T1), agreed by the quorum (T2), and committed immutably (T6). **The gate executes it and signs it.** **Scope statement:** the control plane enforces operational validity, authorization provenance, agreement, and non-repudiation; it does **not** evaluate semantic truth, goal alignment, or latent intent. A structurally valid, authorized, judge-approved proposal is executed and recorded even if the model's intent was adversarial.

**What the control plane is therefore FOR, against T7** (the part the pure-weakness framing misses): because no node can prove its own semantic soundness, the honest aim is **detection and attribution, not prevention** — the immutable, independently-checkable record means a subverted action is non-repudiably recorded, cross-verifiable by a peer, and attributable to a node, so the mesh can **isolate** a node that begins emitting structurally-clean-but-harmful actions. The only *in-band* semantic check is the covenant's output/semantic judge layer, which is **separate from T0–T6, weaker, and its limits must be published** (ours: the 94% false-clear above). Treat semantic safety as defense-in-depth on top of this standard, never as something this standard provides.

## 3. Adoption path
Verify **T0** first (declare the boundary; prove no bypass within it) → implement **T1–T4** (T1 highest-leverage) → run an **independent cold-start verifier** against your own public record ("is history intact? did the rules hold?", any language, public record alone; conformance vectors being published) → **cross-verify with one peer** (disagreement is the finding) → **arm the off-host pieces** (T6) → connect heterogeneous AIs via the plug (SENSE→REPORT→PROPOSE, gated) → **publish your T7 boundary and your semantic layer's measured limits** so no adopter mistakes the control plane for semantic safety.

## 4. What this does NOT do / the operator's step
Does not detect adversarial AIs, defend networks or weights, judge semantic intent (T7), or secure non-adopters. Reaching builders / security-research / standards / government is the operator's outward act through real channels; this is material, not a deployment, and authorizes nothing. No funding asks. Invite serious adopters to **red-team it**. Patterns, not proof. **No final version — this improves as it is attacked.**
