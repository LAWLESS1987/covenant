## Option B — thread (5 posts)

**1/**
> Built an open-source memory system for AI agents. Plain markdown files, a
> hash-chained ledger, an API small enough that an agent learns it from
> /openapi.json without being told.
>
> The design rule: nothing is silently discarded.

**2/**
> Letta got tiered memory right. Mem0 got the add/update/reconcile loop right.
> Supermemory got the universal API right. Engram got consolidation right.
>
> All of them overwrite the thing they disagree with. That's the part I changed.

**3/**
> An update doesn't destroy the old fact — it SUPERSEDES it. Both survive,
> linked both ways, the move recorded on the ledger.
>
> So after a memory turns out to be wrong you can still answer: what did we
> believe before, and when did that change?

**4/**
> And when two agents contradict each other, nothing auto-resolves. Both
> memories are kept and the disagreement is surfaced.
>
> Two AIs disagreeing is a fact a human should see, not a merge conflict to
> silently pick a winner for.

**5/**

## Notes on tone

Deliberately no hashtags, no "🚀", no "game-changing". The claim that carries
this is the specific one — *they overwrite, this supersedes* — and stacking
adjectives on top of a specific claim only makes it sound less true.

The last line of thread post 5 is doing real work: naming a known limitation in
an announcement is the thing that makes the rest of it credible.
