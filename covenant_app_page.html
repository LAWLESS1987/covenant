Actions a fixed allowlist of scripts already in this folder — never a command string

Transact signed in the server process; the key is never read into this page

Four rules, structural
  1. Loopback only. BIND_HOST is 127.0.0.1, main() refuses to start otherwise, and every request is checked again at the handler. No environment variable moves it.
  2. Actions are a fixed allowlist of scripts in this folder. Nothing from a request reaches a shell, an argument list or a path.
  3. Actions are off until COVENANT_APP_ACTIONS=1 exactly. No value of it relaxes anything else.
  4. The signing key is read at the moment of signing, used, and dropped — never logged, never in a response, never in this page.
